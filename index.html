2. Zweck der Datenverarbeitung

Die Gemeinschaft der Wohnungseigentümer verarbeitet personenbezogene Daten zur ordnungsgemäßen Verwaltung des gemeinschaftlichen Eigentums.

Hierzu gehören insbesondere:

  • Verwaltung der Wohnungseigentümer
  • Hausgeldabrechnungen und Wirtschaftspläne
  • Buchführung und Zahlungszuordnung
  • Verarbeitung von Rechnungen und Belegen
  • Verwaltung von Bankkontoinformationen
  • Dokumentation von Verwaltungsvorgängen

Hierbei können Namen, Kontaktdaten, Eigentumsverhältnisse, Zahlungsinformationen und weitere für die Verwaltung erforderliche Daten verarbeitet werden.

Dabei können insbesondere folgende Informationen verarbeitet werden:

  • Kontostände
  • Buchungsdatum und Wertstellungsdatum
  • Zahlungsbeträge
  • Verwendungszwecke
  • Angaben zu Zahlungspartnern
  • Weitere von der Bank bereitgestellte Buchungsinformationen

Die Daten dienen der Zuordnung von Zahlungseingängen und Ausgaben, der Kontenabstimmung und der Erstellung von WEG-Abrechnungen.

Die Bankanbindung befindet sich derzeit in Vorbereitung.

4. Rechtsgrundlagen

Personenbezogene Daten werden verarbeitet, soweit dies zur Erfüllung gesetzlicher Verpflichtungen erforderlich ist, insbesondere auf Grundlage von Art. 6 Abs. 1 lit. c DSGVO.

Soweit einschlägig, kann eine Verarbeitung außerdem auf berechtigte Interessen gemäß Art. 6 Abs. 1 lit. f DSGVO gestützt werden.

5. Speicherung und Zugriff

Die Hausverwaltungssoftware HaVeWa wird auf einem selbst verwalteten Server betrieben.

Der Zugriff auf personenbezogene Verwaltungsdaten ist auf entsprechend berechtigte Personen beschränkt.

Die Daten werden grundsätzlich nur so lange gespeichert, wie sie für die jeweiligen Verwaltungszwecke benötigt werden oder gesetzliche Aufbewahrungspflichten bestehen.

6. Empfänger personenbezogener Daten

Personenbezogene Daten können im Rahmen der WEG-Verwaltung an berechtigte Wohnungseigentümer, beteiligte Dienstleister und zuständige Stellen übermittelt werden, soweit dies erforderlich und rechtlich zulässig ist.

Für die geplante Bankanbindung wird Enable Banking als technischer Dienstleister eingesetzt.

Die konkreten datenschutzrechtlichen Bedingungen der API-Anbindung werden vor dem produktiven Einsatz geprüft.

  • Auskunft über personenbezogene Daten
